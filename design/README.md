# Packman UI mockups

Two design directions for the Packman shell, as a design canvas.

- `Main.dc.html`, `CreateA.dc.html` — **Direction A**: Packman's existing design
  system (flat, 0-radius, amber `#E0A050`, Instrument Sans / JetBrains Mono /
  Martian Mono), with an animated beam pipeline and a bento-grid Mission Control.
- `MainB.dc.html`, `CreateB.dc.html` — **Direction B**: the same two screens
  rebuilt on [WPF UI](https://wpfui.lepo.co/) — Mica, custom TitleBar,
  NavigationView, InfoBar, CardExpander — with amber kept as the accent.
- `canvas.json` — artboard layout.
- `packman-redesign.html` — the seeded canvas; open in a browser, or use the
  published link.

Nothing here is wired to the app; these are mockups.
